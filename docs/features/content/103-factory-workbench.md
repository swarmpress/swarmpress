# The Factory workbench

The tool graph editor in the Studio's grammar: machines from the closed node catalogue, couplings by type (round scalar, square object, ribbed list), tubes checked on every move, recipes, test-run replay of the trace, and n8n import as a booklet. See [the design](../../design/brick-studio.md) and [ADR-0077](../../adr/0077-the-brick-studio.md).
