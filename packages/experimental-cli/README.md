# @swarm-press/experimental-cli

Experimental: not integrated into main workflows. See plan-doc audit item 32.

This package contains the prototype operator CLI (`swarmpress`). It is kept
in the workspace for future revival but is not wired into the production
agent / workflow / admin stack. Do not depend on it from other packages.

## Local use

```bash
pnpm --filter @swarm-press/experimental-cli cli -- --help
```
